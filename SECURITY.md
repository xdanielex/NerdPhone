# Security and safety

This is experimental mining software, not a wallet. Never enter a seed phrase or private key. Only use a public payout address and a non-sensitive pool password.

Stratum connections are plaintext TCP, not TLS. Local preferences are not an encrypted credential vault. Avoid credentials reused elsewhere.

Do not publish vulnerabilities with private data in public issues. Contact your repository maintainer privately once you have chosen and published a security contact; none is configured in this template.

CPU-intensive mining can heat the phone, degrade its battery and drain power. OS thermal and battery protections remain in control. Stop using a swollen or damaged battery. Store eligibility and continuous background execution are not guaranteed.

Never upload your Android signing key, local.properties or generated SDK files. For releases, use a private signing key with a documented backup/update strategy. Debug builds are not a substitute for release signing.
