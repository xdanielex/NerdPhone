# NerdPhone app icon

Selected AI-generated artwork was adapted into raster launcher resources. The icon combines a phone, Bitcoin symbol and circuit motif. It is not an affiliation/endorsement mark of NerdMiner, Bitcoin developers, Android or a pool operator, and has not been independently trademark-cleared.

- `nerdphone-icon-1024.png`: high-resolution square artwork.
- `nerdphone-icon-512.png`: smaller public/download asset.
- Android resources: density-specific legacy square/round icons, adaptive foreground/background for API 26+, and themed monochrome layer for API 33+.

Artwork is provided as part of this project's MIT distribution to the extent the contributors can grant rights; no exclusivity or trademark-rights guarantee is made. Real app/pool screenshots remain separate and must not be fabricated from this artwork.
